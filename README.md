## Requirements

- Python 3
- `antlr4-python3-runtime` 4.13.2
- `antlr4-tools` 0.2.2 

Setup:

```
py -m pip install antlr4-tools antlr4-python3-runtime
```

## Main Files

- `Python.g4`: the grammar
- `main.py`: reads an input file and prints the parse tree
- `test.py`: sample/test input

Everything else including: `Python.interp`, `Python.tokens`, `PythonLexer.py`, `PythonLexer.tokens`, `PythonListener.py`, and `PythonParser.py` are autogenerated by ANTLR and can be safely deleted at any time. They will be regenerated with the 1st command listed in the how to use section!

## How to Use

1. Generate the lexer and parser from the grammar (rerun this after any grammar change):

```
py -c "import antlr4_tool_runner as a; a.tool()" -Dlanguage=Python3 Python.g4
```

2. Run the parser on an input file:

```
py main.py test.py
```

## What to Expect When Running

Example input:

```
x = 5
y = x + 2 + 3
```

Example output:

```
(program (statement (assignment x = (expr 5))) \n (statement (assignment y = (expr (expr (expr x) + (expr 2)) + (expr 3)))) \n <EOF>)
```
