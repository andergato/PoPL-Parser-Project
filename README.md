# Python Parser Project

## About

**THIS IS A PARTIAL IMPLEMENTATION** Delete this before submitting ;)

Currently supported (Deliverable 1):
- Addition (`+`)
- Assignment (`=`)
- ID/Number/Boolean/Strings
- Whitespace, and line parsing
- Arrays of ints, floats, strings
- Multi-dimensional arrays

Currently supported (Deliverable 2):
- `if` / `elif` / `else` blocks
- Comparison operators (`<`, `<=`, `>`, `>=`, `==`, `!=`)
- Logical operators (`and`, `or`, `not`) and parenthesized conditions
- Indentation-sensitive blocks (the lexer emits `INDENT`/`DEDENT` tokens)
- Nested `if` blocks
- Subtraction, multiplication, division, modulo, and the other assignment operators (`+=`, `-=`, `*=`, `/=`)

## Main Files

All in `PyParser/`:

- `deliverable2.g4`: the grammar (`deliverable1.g4` is the Deliverable 1 version)
- `deliverable2.py`: reads an input file and prints the parse tree (`deliverable1.py` is the Deliverable 1 version)
- `project_deliverable_2.py`: sample/test input
- `test_deliverable2.py`: unit tests

Everything else including: `deliverable2.interp`, `deliverable2.tokens`, `deliverable2Lexer.py`, `deliverable2Lexer.tokens`, `deliverable2Listener.py`, and `deliverable2Parser.py` are autogenerated by ANTLR and can be safely deleted at any time. They will be regenerated with the 1st command listed in the how to use section!

## How to Use

1. From the `PyParser` folder, generate the lexer and parser from the grammar (rerun this after any grammar change):

```
py -c "import antlr4_tool_runner as a; a.tool()" -Dlanguage=Python3 deliverable2.g4
```

2. Run the parser on an input file (defaults to `project_deliverable_2.py`):

```
py deliverable2.py project_deliverable_2.py
```

3. Optionally, run the tests:

```
py test_deliverable2.py
```

## What to Expect When Running

Example input:

```
x = 5
if x > 3:
    y = x + 1
else:
    y = 0
```

Example output:

```
(program (statement (simple_statement (assignment x = (expr (atom 5)))) \n) (statement (compound_statement (if_statement if (condition (expr (atom x)) > (expr (atom 3))) : (suite \n     <INDENT> (statement (simple_statement (assignment y = (expr (expr (atom x)) + (expr (atom 1))))) \n) <DEDENT>) (else_clause else : (suite \n     <INDENT> (statement (simple_statement (assignment y = (expr (atom 0)))) \n) <DEDENT>))))) <EOF>)
```

Syntax errors are printed to the terminal, e.g. `line 2:0 missing INDENT at 'x'`.
